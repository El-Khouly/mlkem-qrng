Put your bitstream here, e.g. `data/RNG_Bits.txt`.

Accepted formats (set `STREAM_FMT` in the notebook):
- `ascii`: a text file of `0` and `1` characters; any other characters (newlines, spaces, commas) are ignored.
- `bin`: raw bytes, read most-significant bit first.

Files in this folder are ignored by git, so your stream is not published by accident.
